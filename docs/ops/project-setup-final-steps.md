# Project Setup - Final Steps

## Add Status Field Options (UI Required)

The Status field currently has: Todo, In Progress, Done

To add Backlog, In Review, and Blocked:

1. Go to your Project: https://github.com/users/chrisbelyea/projects/2
2. Click the ⋯ (three dots) in the top-right → Settings
3. In the left sidebar, click "Fields"
4. Find "Status" and click "Edit"
5. Add three new options:
   - Backlog
   - In Review
   - Blocked
6. Optionally reorder: Backlog → Todo → In Progress → In Review → Done → Blocked
7. Save

## Alternative: Use Default Columns

You can also work with the default Todo/In Progress/Done and manually organize via labels or other fields if preferred.
